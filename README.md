# vitalpeak
Web de gimnasio y salud

## Arranque local
```bash
run.bat
```
o: `pip install -r requirements.txt` → `streamlit run streamlit_app.py`

## Creador de rutinas con IA (Ollama gratis)
1. Instala [Ollama](https://ollama.com) y ejecuta `ollama pull qwen2.5:14b`
2. Copia `.env.example` a `.env`
3. En Streamlit, abre la página **Creador Rutinas IA**
